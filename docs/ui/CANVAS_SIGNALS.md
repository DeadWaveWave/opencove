# Canvas Signals

> 关联全局 UI 规范：`docs/ui/README.md`；几何、节奏与减弱动态约束见 [Spatial Pixel](./SPATIAL_PIXEL_THEME.md)。

画布用光、波纹和粒子说明窗口在做什么。本文记录这些信号的触发来源、节奏、尺寸和关闭条件。

## 状态信号

- 普通终端的 PTY 输出每窗口最多 700ms 触发一次涟漪与工作灯增亮；Agent 的原始 PTY 重绘
  不触发这两种效果。Agent 信号只跟随权威状态，未来可由 ACP 消息事件补充输出信号。
- 涟漪使用 Tide 的高斯环带与各状态独立形状；等待信标每 1300ms、工作声纳每 2400ms，
  完成同时发出类别色波与白色波峰。最多保留 24 道，满额时移除最旧波；玻璃后仍受亮度上限约束。
- 工作灯按窗口 id 错相呼吸（2400ms），等待灯随信标起伏（1300ms）；完成与失败叠加 1500ms
  衰减闪光。新窗口淡入 700ms，加载/恢复窗口直接亮起；关闭信号或减弱动态时固定亮度并清除能量。
- 完成波连续采样其他窗口的轮廓亮度，用发送窗口的类别墨色显示独立蒙版细边；波结束、
  页面隐藏、关闭信号或减弱动态都会清零，不改变正文后方填充。
- 等待窗口按权威状态显示琥珀边框和屏幕尺寸固定的 halo（1px 细边、28px 模糊、3px 扩散）；
  仅透明度以 1300ms 起伏。减弱动态或关闭信号保持 0.8；失败窗口持续显示红边直到状态改变。
  装饰层独立于玻璃 rim，不改变正文填充或窗口选择状态。
- 完成闪光是屏幕尺寸固定的独立层，用类别字形色（原型的 `--ki`；火花和细边用墨色）：2px 细边、
  54px 模糊、8px 扩散、55% 混合，
  仅透明度在 1 秒内淡出；减弱动态时以 0.9 保持 600ms 后消失。失败使用 280ms 五段扫描线错位，
  不覆盖 React Flow 定位 transform；减弱动态只保留状态红边。关闭动态信号不播放两种瞬时动效。
- 从收件箱、命令中心、侧栏、活动摘要或边缘信标跳转到窗口后，显示 2.4 秒强调色光晕和四个
  像素角标；新跳转替换旧高亮，不保存、不改变选中 ID。角标外扩 7 世界像素，每角由 10×2 和
  2×10 像素条组成；减弱动态和关闭装饰信号仍保留这个静态导航反馈，卸载与项目切换清理。
- 边缘信标保留全色等待边框和 4px / 16% 静态外圈，只有 8px 方点以 1300ms 在 0.3–1 之间
  起伏；减弱动态或关闭信号时方点静止。侧栏工作中的 Agent 保留强调色状态文字，不使用旋转 spinner。

## 像素墙光照

像素墙的云、色相与 shimmer 使用固定世界尺寸；网格合并或拆分只重采样同一色场。
工作光的衰减距离随连续缩放变化，保持远景窗口外的可见光晕。参见 [Pixel wall](SPATIAL_PIXEL_THEME.md#pixel-wall)。
浅色模式的工作光依窗口宽高向右下偏移，用较紧的连续衰减模拟彩色玻璃投下的日光；
玻璃遮罩仍跟随原始窗口，背景明暗渐变按整个视口计算。
光标照明在工作光和波纹之后叠加，与窗口的类别色混合而不是被它盖住：深色主题按加色（screen）提亮，浅色主题保留原型向 accent 着色；深浅主题均用 accent 第 9 阶。
窗口内不加光，边缘连续衰减，玻璃和外壳只使用剩余对比度预算；关闭背景闪烁或减少动态时关闭照明。

## 工作中巡航

- Working 外框巡航只消费现有 Agent 状态：两串各 8 粒，头部 3.5px、其余 2.5px，
  间距 11px、外扩 6px，都是屏幕尺寸，不随画布缩放变化；位置按 DPR（最多 2）对齐。
- 颜色来自 `--cove-kind-<族>-ink`（深色第 11 阶、浅色第 9 阶；中性第 10 / 9 阶），
  主题没有类别 token 时回退到已有像素调色板。减少动态效果显示静态细框，关闭信号则不画。
- 速度沿用 Tide 原型的 240 世界像素/秒；实际外扩路径每圈多出 `48 / zoom` 世界像素。
  尺寸与间距的回归用真实 Canvas 绘制记录，避免 runner 错过瞬时画面。

- LOD 真正切换时，每个可见展开窗口散出 10 粒类别 ink 火花；完成/失败只订阅既有
  `windowSignalEvents`，分别散出 26 粒 ink / 14 粒红色火花。CSS 仍负责外框闪光与失败
  抖动，角落火花由画布替代。粒子最多 1200 个，复用 30/10/0 fps 调度，不创建独立定时器。
- 粒子记录世界坐标，屏幕尺寸只按 `clamp(zoom, 0.55, 1.2)` 调整；减少动态效果、关闭信号、
  隐藏与卸载时清空且不重放。LOD 直接读取原有 owner 的属性，不另算阈值。

## 创建与关闭

- 创建的 rim 与组装粒子统一使用 `--cove-kind-<族>-ink`，颜色不随屏幕位置变化；关闭碎片
  以约 50/50 混合类别 solid / ink，按场景内粒子索引固定选择，连续帧不闪色。
- 类别由 `resolveWindowKindFamily` 派生，关闭快照与几何一起复制类别值，移除节点后不再查找
  节点或保留节点引用。颜色复用主题读取器，随主题切换刷新；缺少类别 token 时沿用 Pixel
  调色板与文字色兜底。形状、时间线、readiness、上限和减少动态效果行为保持原有契约。
