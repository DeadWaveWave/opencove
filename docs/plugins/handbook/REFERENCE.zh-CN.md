## 将资料交给 Agent

将下面的命令复制到终端或 Agent 任务中：

```sh
opencove plugin guide
```

结果包含 Agent 可以直接读取的本地路径。让它遵循随附的 API 与视觉指南，
在独立目录中创建插件，安装到指定运行环境，并验证它声明的能力。
如果插件提供节点窗口，就验证真实窗口与预览；只提供后台指令或其他扩展的插件不需要窗口。
单独制作一个网页并不等于安装了 OpenCove 插件。

如果 CLI 启动器需要修复，前往**设置 → 连接 → CLI → 安装 CLI**。
具体环境准备步骤见[开发与验证](../AUTHORING.md)。
