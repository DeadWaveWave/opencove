# 把自己的工具放进工作空间

插件把实用工具带到你工作的地方。它可以显示时钟、提供专注的画布窗口，
也可以提供让 Agent 执行的命令。每个插件自行声明它支持的功能。

OpenCove 负责窗口的移动、缩放、收起和关闭，插件负责窗口里的内容。
你可以把工具放在终端、笔记和任务旁边，直接在同一个画布中使用。

## 插件的使用方式

| 提供的能力 | 在哪里找到 |
| --- | --- |
| 画布窗口 | 插件声明的画布操作栏或右键菜单入口 |
| 命令 | 插件详情页列出命令与调用方式 |
| Skill | 在详情页复制安装提示词，交给 Agent 安装 |
| 偏好设置 | 插件声明的控件会出现在详情页 |
| 主题 | 已启用插件提供的主题显示在设置 → 外观中 |

有些插件完全不需要窗口。详情页会显示插件实际提供的能力，以及 README、
版本和可选的交互预览。

命令还可以出现在命令中心，以及声明的画布、节点或 Space 菜单中。
这些入口使用 OpenCove 提供的上下文，窗口命令需要可用的目标视图。
具体规则见[主机扩展能力](../HOST_EXTENSIONS.md)。

## 管理自己的插件

在 **设置 → 插件** 中查看已安装的插件，点击列表项进入详情。
开关控制插件是否运行；隐藏操作栏或右键菜单入口只改变快捷入口的显示位置。

停用插件会保留已有窗口和保存的数据。关闭窗口会结束该视图，收起则保持视图挂载。
**卸载**会移除安装记录，但保留源文件与私有数据，便于重新安装。

## 先试试交互预览

插件提供预览时，可在详情中点击**启动预览**。拖动、缩放、收起示例窗口，
再试用其中的控件。预览的数据和后端与真实窗口隔离，关闭预览后会停止运行。
插件作者应明确标注示例内容，并避免在预览中执行外部工作。
